# Multi LanChat

Мост между **VK**, **Telegram**, **Max** и **LanChat** (чат с темами). Входящие сообщения из мессенджеров попадают в отдельную тему; ответ оператора в теме уходит человеку.


В этом репозитории — готовая сборка: скомпилированный сервер и веб-интерфейс. Исходники сюда не входят.

## Требования

- Node.js **22.12+**
- доступ к LanChat (LPAT и родительский чат с темами)

## Если TLS/сертификаты Минцифры не доверены

Если в логах видишь ошибки вида `unable to get local issuer` / `certificate verify failed` при запросах к российским доменам, установи корневые сертификаты Минцифры:

1. Открой: [https://www.gosuslugi.ru/crt](https://www.gosuslugi.ru/crt)
2. Затем можно автоматом (Linux/macOS/Windows) запустить:

```bash
node scripts/install-gosuslugi-crt.mjs
```

Или самостоятельно скачайте сертификат с Гос Услуг и установите его на устройство  
После установки:

- перезапусти мост
- на macOS/Linux иногда нужно принудительно дать Node доверие через `NODE_EXTRA_CA_CERTS`:

```bash
export NODE_EXTRA_CA_CERTS="$HOME/.config/multi-lanchat/certs/russian-trustedca.pem"
```



## Запуск

```bash
npm install
cp .env.example .env
npm start
```

Откройте [http://127.0.0.1:3040](http://127.0.0.1:3040). Данные хранятся в `data/bridge.sqlite` (каталог создаётся сам).

По умолчанию сервер слушает только localhost. Для доступа с других машин в `.env`:

```bash
HOST=0.0.0.0
PORT=3040
```



## Настройка

1. **Настройки** — URL публичного API LanChat, LPAT, UUID родительского чата с темами, WebSocket.
2. **Модули** — добавьте один или несколько аккаунтов:
  - **VK** — токен сообщества и ID группы
  - **Telegram** — токен бота
  - **Max** — токен бота с [dev.max.ru](https://dev.max.ru). Для long poll webhook у бота должен быть выключен
3. **Запустить** мост в боковой панели.

Модули можно включать и выключать без правки файлов. Каждому аккаунту соответствует своя тема.

Опционально задайте `BRIDGE_UI_TOKEN` в `.env` — интерфейс и API (кроме `/api/health`) будут требовать этот токен.

## Что умеет

- несколько VK-сообществ, Telegram-ботов и Max-ботов одновременно
- живой статус, журнал и дашборд
- маршруты ответа: реплай в теме → тот же диалог в мессенджере
- вложения в обе стороны (фото, видео, аудио, файлы)



## Вложения

Файлы передаются **в обе стороны**. Перед загрузкой в LanChat действует проверка: html/js/svg/xml, PDF со скриптами, RAW-камеры, пустые и файлы больше ~45 МБ отбрасываются. Максимум **8 файлов** на сообщение.


|              | LanChat                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------------- |
| **Telegram** | фото, документ, видео, аудио, голосовое, video note, стикер, GIF                                     |
| **VK**       | фото, документ, аудио / голосовое, graffiti, стикер. Видео VK без прямой ссылки часто не скачивается |
| **Max**      | image, video, audio, file (нужна прямая ссылка или загрузка через `/uploads`)                        |


Из LanChat обратно: картинки в TG/VK как photo, видео/аудио своим типом, остальное как document/doc/file. Остальной текст уходит даже если файл отсеялся.

## Безопасность

- не коммитьте `.env` и `data/`
- токены мессенджеров и LPAT хранятся только локально в SQLite
- без `BRIDGE_UI_TOKEN` панель открыта всем, кто достучался до порта



## Обновление

Скачайте свежую сборку, остановите процесс, замените файлы, снова `npm install` и `npm start`. Файл `data/bridge.sqlite` не трогайте — там аккаунты и маршруты.
