# Multi LanChat

Мост между **VK**, **Telegram**, **Max** и **LanChat** (чат с темами). Входящие сообщения из мессенджеров попадают в отдельную тему; ответ оператора в теме уходит человеку.
<img width="1512" height="824" alt="Screenshot 2026-08-17 at 22 57 25" src="https://github.com/user-attachments/assets/f9247697-4348-4abc-b2eb-b49950162c84" />

В этом репозитории — готовая сборка: скомпилированный сервер и веб-интерфейс. Исходники сюда не входят.

## Требования

- Node.js **22.12+**
- доступ к LanChat (LPAT и родительский чат с темами)

## Запуск

```bash
npm install
cp .env.example .env
npm start
```

Откройте [http://127.0.0.1:3040](http://127.0.0.1:3040). Данные хранятся в `data/bridge.sqlite` (каталог создаётся сам).

По умолчанию сервер слушает только localhost. Для доступа с других машин в `.env`:

```bash
HOST=0.0.0.0
PORT=3040
```

## Настройка

1. **Настройки** — URL публичного API LanChat, LPAT, UUID родительского чата с темами, WebSocket.
2. **Модули** — добавьте один или несколько аккаунтов:
   - **VK** — токен сообщества и ID группы
   - **Telegram** — токен бота
   - **Max** — токен бота с [dev.max.ru](https://dev.max.ru). Для long poll webhook у бота должен быть выключен
   <img width="513" height="665" alt="image" src="https://github.com/user-attachments/assets/c159651e-ded9-4183-843a-13e43a59c435" />

3. **Запустить** мост в боковой панели.

Модули можно включать и выключать без правки файлов. Каждому аккаунту соответствует своя тема.

Опционально задайте `BRIDGE_UI_TOKEN` в `.env` — интерфейс и API (кроме `/api/health`) будут требовать этот токен.

## Что умеет

- несколько VK-сообществ, Telegram-ботов и Max-ботов одновременно
- живой статус, журнал и дашборд
- маршруты ответа: реплай в теме → тот же диалог в мессенджере

## Безопасность

- не коммитьте `.env` и `data/`
- токены мессенджеров и LPAT хранятся только локально в SQLite
- без `BRIDGE_UI_TOKEN` панель открыта всем, кто достучался до порта

## Обновление

Скачайте свежую сборку, остановите процесс, замените файлы, снова `npm install` и `npm start`. Файл `data/bridge.sqlite` не трогайте — там аккаунты и маршруты.
